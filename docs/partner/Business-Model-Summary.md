# AN ACT — Business Model Summary (Partner Package)

**Audience:** Investors, strategic partners, industry specialists

---

## Value proposition

AN ACT connects **professional need** with **trusted action** through a Runtime JSON platform where every screen is server-authoritative and every journey is auditable.

## Customer journey

Splash → Registration → Need → Search → Request → Contract → Action → Execution → Completion → Feedback

## Provider journey

Registration → Living onboarding → Profile + passport → Action Mode execution

## Revenue model (platform design)

| Stream | Mechanism |
|---|---|
| Marketplace transactions | Contract lifecycle with escrow-ready architecture |
| Provider subscriptions | Professional passport + tier progression |
| Intelligence services | AI guidance, contract intelligence, matching |
| Enterprise partnerships | Executive experience layer, government partnership center |

## Competitive differentiation

1. **Runtime JSON architecture** — single contract for web, mobile, Bubble
2. **Knowledge Bank** — compiled intelligence from 50+ engines
3. **Trust Live Frame** — presentation-tier trust without client-side calculation
4. **Full journey** — need through completion in one platform

## Market opportunity

- Professional services marketplace (MENA focus in demo data)
- Skilled trades, consulting, and project-based action
- Intelligence-driven matching and contract automation

## Partner integration paths

- Bubble onboarding via Runtime JSON shell compatibility
- API-first integration for technology partners
- Executive presentation layer for investor/government audiences
